# SimpleFinanceManager---Java.

SimpleFinanceManager is a Java-based console application that helps users manage their personal finances by storing income and expense transactions in a MySQL database. It supports full CRUD operations, real-time budget calculations, and financial goal planning.

📌 Key Features
. 📥 Add Transactions – Record incomes and expenses with categories and dates

. ✏️ Update/Delete Transactions – Modify or remove records based on transaction ID

. 📊 Show All Transactions – View a list of all financial activities

. 💰 Budget Checker – Calculate total income, total expenses, and net savings

. 🎯 Financial Advice – Get smart monthly/annual savings goals based on your input

. 🛢️ MySQL Database Integration – Automatically creates and manages the database and table

🧰 Tech Stack
. Java (JDBC + Core)

. MySQL

. SQL

. CLI (Command Line Interface)

🚀 How to Run
1. Make sure MySQL is installed and running on localhost:3306

2. Update your MySQL username/password in the connectToDatabase() method

3. Compile and run the Java program:

. javac SimpleFinanceManager.java

. java SimpleFinanceManager
